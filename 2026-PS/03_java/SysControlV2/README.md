# SysControl v2.0

## Aluna
Mayara

## Variante
Produto

## Descrição

Este projeto foi desenvolvido para a atividade SysControl v2.0 utilizando Programação Orientada a Objetos em Java.

## Atributos

- codigo
- nome
- preco
- quantidade

## Validações implementadas

- Nome não pode ser vazio.
- Preço não pode ser negativo.
- Quantidade não pode ser negativa.

## Métodos de comportamento

- adicionarEstoque()
- removerEstoque()
- calcularValorEmEstoque()

## Desafios complementares

- Construtor alternativo.
- Método resumo().

## Casos de teste

1. Criação de produtos válidos.
2. Tentativa de alterar o nome para vazio.
3. Tentativa de definir preço negativo.
4. Adição ao estoque.
5. Tentativa de remover mais produtos do que existem em estoque.
